# Glossary

## AD-ORDINEM

A public specification for deterministic governance of Kubernetes and Linux infrastructure.

## ChangeRecord

A public artifact family used to describe a declared change as a reviewable event.

## GovernanceManifest

A public artifact family used to describe governance expectations and declared surfaces.

## EvidencePack

A public artifact family used to group references that support review of a declared change.

## ReviewReference

A public artifact family used to connect a declared change to a review target.

## External Governance Model

A governance model in which structural authority is separated from runtime execution.

## Shell-TerRing

An external operational foundation described by the AD-ORDINEM public specification.

## Philologic Operative Language

The declarative grammar through which AD-ORDINEM describes, reviews, versions, and governs infrastructure structure.
