# Governance Artifact Schema Notes

This document describes the public structure expected from AD-ORDINEM illustrative governance artifacts.

## Artifact Families

The current public examples use two artifact families:

- `GovernanceManifest`;
- `ChangeRecord`.

## GovernanceManifest

A governance manifest describes the intended governance model, declared surfaces, validation expectations, and publication status of an illustrative governance surface.

## ChangeRecord

A change record describes a declared infrastructure change as a reviewable event.

## Status

These structures are illustrative and will evolve through public review.
