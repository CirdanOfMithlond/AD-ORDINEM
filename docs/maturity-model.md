# Public Maturity Model

This document defines a public maturity path for AD-ORDINEM.

## Level 0: Public Specification

The repository defines terms, scope, examples, and review notes.

## Level 1: Public Artifact Model

The repository defines stable public artifact families such as change records, governance manifests, evidence packs, and review references.

## Level 2: Public Validation

The repository adds lightweight checks for required files, artifact markers, and example consistency.

## Level 3: Reference Examples

The repository adds richer examples showing how public artifacts relate to each other.

## Level 4: Reference Tooling

The repository adds safe, implementation-neutral tooling around public artifacts.

## Current Position

AD-ORDINEM is between Level 1 and Level 2: the public specification is present, initial examples exist, and a lightweight checker has been added.
