# Publication Boundary

This document describes the public scope of the AD-ORDINEM repository.

## Public Scope

The repository contains public architecture notes, examples, schemas, roadmap material, reviewer guidance, publication-boundary notes, and contribution guidance.

It is intended to make the specification layer reviewable before the full implementation surface is made public.

## Current Boundary

The current public repository includes:

- architecture notes;
- project brief material;
- public white-paper summary;
- reviewer guidance;
- illustrative governance manifests;
- illustrative change records;
- security and non-goal boundaries;
- roadmap material.

## Material Outside the Current Boundary

Associated implementation work may exist separately as preparatory material.

That material is not represented as production-ready public software until it has been reviewed, reduced to non-sensitive components, documented, and aligned with the public specification.

## Staged Publication Rationale

The staged approach is intentional.

Infrastructure-governance material can involve privileged operational patterns, sensitive deployment assumptions, and security-relevant implementation details. AD-ORDINEM therefore publishes the specification and example layer first, then expands public implementation material only when it can be reviewed safely.

## Future Expansion

Future work may expand the public specification when additional material is ready for publication.

The immediate publication plan is to complete the technical white paper, expand examples, define validation expectations, and prepare safe implementation-neutral assets for public review.
