# Public Use Cases

This document lists public use cases for AD-ORDINEM.

## Use Case 1: Declared Infrastructure Change

A platform team wants each infrastructure change to have a declared intent, review status, scope, and rollback reference.

## Use Case 2: Reviewable Governance Manifest

A Kubernetes operator wants a manifest that describes governance expectations without relying on hidden operational context.

## Use Case 3: Audit-Oriented Evidence Notes

An SRE team wants infrastructure changes to produce reviewable evidence references before and after a declared transition.

## Use Case 4: Rollback-Aware Operations

A platform team wants rollback references to be visible as part of the change record rather than reconstructed after failure.

## Use Case 5: Specification-Driven Tooling

A maintainer wants public artifact structures that can later support validation, examples, and reference implementation work.
