# Examples

This directory contains non-sensitive reference examples for the public AD-ORDINEM specification.

The examples are illustrative only. They are not production deployment artifacts.

## Files

- `change-record.yaml`: minimal example of a declared infrastructure change record.
- `minimal-governance-manifest.yaml`: minimal example of a governance manifest.

## Safety Notice

Do not apply these files directly to a production system.

They are intended to document structure, terminology, and review surfaces.
