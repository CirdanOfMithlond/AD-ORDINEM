# Roadmap

AD-ORDINEM is currently in early public specification stage. The roadmap below describes the intended progression from public specification material to reviewable, implementation-neutral open-source assets.

## Phase 0: Public Specification Stabilization

- publish a clean repository-level README;
- define the public scope of the repository;
- separate public specification material from private implementation work;
- document non-goals and safety boundaries;
- publish a public white-paper summary.

## Phase 1: Reference Governance Artifacts

- add minimal governance manifest examples;
- add change-record examples;
- define naming and versioning conventions;
- define evidence-pack structure;
- define rollback metadata structure;
- document how governance artifacts should be reviewed.

## Phase 2: Validation and Safety

- add static validation examples;
- define validation expectations for public examples;
- add security review checklist;
- add threat-modeling notes for governance boundaries;
- add documentation consistency checks.

## Phase 3: Reference Implementation Preview

- publish non-sensitive shell utilities;
- publish Kubernetes-safe example manifests;
- add implementation-neutral workflow examples;
- add release packaging for public specification assets;
- add maintainer documentation.

## Phase 4: Community Review

- open issues for architectural review;
- collect feedback from DevOps, SRE, security, and Kubernetes users;
- refine specification boundaries;
- prepare v0.1 public specification release;
- identify safe implementation areas suitable for future publication.
