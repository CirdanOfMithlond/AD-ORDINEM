# Reviewer Guide

This guide helps reviewers understand the public AD-ORDINEM repository quickly.

## Review Path

1. Read `README.md` for project scope.
2. Read `docs/project-brief.md` for the short project rationale.
3. Read `docs/architecture-overview.md` for the public architecture model.
4. Read `docs/public-whitepaper-summary.md` for the public summary.
5. Review `examples/change-record.yaml` and `examples/minimal-governance-manifest.yaml`.
6. Review open issues for active public specification work.

## What To Look For

- deterministic infrastructure change records;
- governance manifests;
- rollback-aware review semantics;
- evidence-oriented change representation;
- planned validation work.

## Repository Status

AD-ORDINEM is in early public specification stage. The repository will be expanded through examples, validation notes, schemas, and reference materials.
