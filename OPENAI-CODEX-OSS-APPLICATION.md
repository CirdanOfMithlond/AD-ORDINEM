# OpenAI Codex OSS Application Brief

## Project

AD-ORDINEM is an early-stage public specification for deterministic governance of Kubernetes and Linux infrastructure.

## Maintainer

Primary maintainer: Luca Arrighi.

## Why the Repository Qualifies

The repository defines a public architecture for infrastructure governance, rollback-aware change records, auditability, and reviewable operational evidence.

It is intended to help platform engineers, SRE teams, DevOps engineers, Kubernetes operators, infrastructure architects, and security reviewers reason about infrastructure change as a declared and reversible event.
